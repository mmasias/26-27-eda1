# Relación con la informática y las elecciones de delegado

- **Array:** Para almacenar los candidatos y el número de votos de cada uno 
- **Cola:** Para representar el orden en el que los alumnos esperan para votar.
- **Pila:** Para guardar temporalemte las acciones ricentes, como votos que se necesiten revisar o simplemente deshacerlos.
- **Lista:** Para almacenar los datos emitido de forma anonima antes de realizar el reecuento, sin guardar relación con dicho alumno que lo haya emitido y poder coger papeletas sin orden alguno.
