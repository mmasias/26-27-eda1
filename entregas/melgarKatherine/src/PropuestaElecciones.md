# Propuesta para elecciones

Para esta propuesta considero hacerlo con arrays porque el número de participantes se define antes de iniciar la votación y no cambiará durante las elecciones

### 1. Array `candidatos`
Arreglo de texto con una longitud fija
* **Contenido:** Nombres de los candidatos registrados
* **Ejemplo:** `["Juan", "Juanito", "Brayan", "Abstención", "Nulo"]`

### 2. Array `votos`
Arreglo numérico

* **Contenido:** Conteo acumulado de votos
* **Ejemplo inicial:** `[0, 0, 0, 0, 0]`
