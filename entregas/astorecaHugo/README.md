# Estructura vista y justificación
## Array
 - Es de tipo int.
 - Almacena los votos que se vayan contando de los candidatos.
 - El array se inicializa como: **candidatos + 2**.
 - También almacena los votos nulos y los votos en abstención como si fuesen también candidatos.
 - El tamaño es de los miembros que están en clase, para ello habría que pasar lista.

 ## Array de candidatos 

  - Es de tipo String porque guarda el nombre de los candidatos de las elecciones.
  - Se inicializa como **# candidatos**.
  - También puede guardar si queremos  los nombres de voto en nulo y voto en blanco ya que son una forma de candidatos .
  - El tamaño también es de los meimbros que están en clase.
