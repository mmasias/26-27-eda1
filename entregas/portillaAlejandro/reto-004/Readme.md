# Estructuras utilizadas y justificación

| **Dato** | **Decisión** | **Justificación** | **Alternativa descartada** | **Limitación asumida** |
|---|---|---|---|---|
| Alumnos presentes en el aula | Lista | El número de alumnos puede variar, ya que se pueden añadir o eliminar nombres. Además, necesitamos comprobar si un alumno está presente antes de permitirle participar. | Un array, porque tiene un tamaño establecido y sería menos cómodo modificar la cantidad de alumnos. | Para comprobar si un alumno está en la lista, hay que recorrer sus elementos hasta encontrarlo o llegar al final. |
| Candidaturas mientras el plazo está abierto | Lista | Mientras se puedan presentar o retirar candidaturas, necesitamos una estructura que permita añadir y eliminar nombres fácilmente. | Un array, porque no conocemos de antemano cuántos alumnos acabarán presentándose. | Cuando se cierre el plazo, tendremos que pasar los candidatos de la lista a un array. |
| Candidaturas al cerrar el plazo | Array de `String` | Una vez cerrado el plazo, el número de candidatos queda fijado. Como ya no se van a modificar las candidaturas, podemos guardarlas en un array. | Una lista, porque ya no necesitamos que el número de elementos cambie durante la votación. | Es necesario copiar los nombres de la lista al array para guardar la lista definitiva de candidatos. |
| Papeletas recogidas pendientes de lectura | Cola | Las papeletas deben procesarse siguiendo el mismo orden en que se han introducido. Una cola permite sacar primero el voto que lleva más tiempo esperando. | Una pila, porque los votos saldrían en orden inverso. Tampoco necesitamos acceder directamente a posiciones concretas, como permitiría un array. | Cuando se extrae una papeleta, deja de estar en la cola y ya no se puede consultar desde ella. |
| Nombres de candidatos, blanco y nulo | Array de `String` | Las opciones de voto son conocidas una vez cerradas las candidaturas. Por eso podemos guardar los nombres de los candidatos y añadir las opciones de voto en blanco y voto nulo. | Una lista, porque no necesitamos incorporar ni eliminar opciones durante el recuento. | Para localizar un nombre hay que recorrer el array hasta encontrarlo. |
| Recuento de votos | Array de `int` | Cada posición almacena el número de votos de una opción. Podemos incrementar el contador cuando llega un voto y reducirlo si necesitamos corregir el recuento. | Una lista, porque el número de opciones de voto permanece fijo y no hace falta añadir ni quitar contadores. | La posición de cada opción debe coincidir con la posición de su contador en el otro array para evitar asignar votos incorrectamente. |
