## Elecciones

Para realizar el ejercicio utilizaría las siguientes estructuras de datos:

- **Array de cadenas de texto:** para almacenar los nombres de los candidatos y las opciones de voto nulo y abstención. Su tamaño es fijo porque las opciones se conocen antes de comenzar la votación.

- **Lista dinámica:** para guardar los nombres de los alumnos que pueden votar, ya que permite añadir o eliminar alumnos fácilmente.

- **Pilas y colas:** para representar el proceso de recogida de las papeletas. La cola permite seguir un orden de recogida, mientras que la pila permite guardar y extraer las papeletas empezando por la última.

- **Array de enteros:** para contar los votos de cada candidato y las demás opciones. Cada posición corresponde a una opción y aumenta en uno cada vez que se recibe un voto.

Estas estructuras permiten organizar la información y contar los votos de forma sencilla.
